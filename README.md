# Bleach Wallpapers — Version 1

This is a Flutter starter project for a wallpaper app.

## Run it
1. Install Flutter and Android Studio.
2. Extract this ZIP.
3. Open the folder in Android Studio.
4. Run `flutter pub get`.
5. Connect an Android phone or start an emulator.
6. Run `flutter run`.

## Current version
- Dark Bleach-style UI
- Home screen
- Categories
- Latest wallpaper grid
- Favorites and Settings navigation placeholders
- Wallpaper preview bottom sheet
- Download / Set Wallpaper buttons as UI placeholders
